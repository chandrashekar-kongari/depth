# Depth — Quiet Product Hero (Light Mode)

Matching light-mode companion to the original Depth Quiet Hero.

- `video/depth-quiet-hero-light.webm` — web-first VP9 video; silent, 1920×1080, 24 fps, 13-second loop.
- `video/depth-quiet-hero-light.mp4` — H.264 fallback.
- `preview/depth-hero-poster-light.png` — light-mode static poster for loading/reduced motion.
- `index.html` — editable, self-contained HTML/CSS/SVG/JS source.
- `source/render.py` — re-render the MP4 (Playwright, Chromium, FFmpeg).

The light mode uses the exact same illustrations, content, and animation timing as dark mode, with a coordinated neutral palette. All findings are illustrative and scripted.
