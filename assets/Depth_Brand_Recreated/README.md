# Depth — Marketing & Brand Asset Kit

A recreated, production-sized identity system based on the user-provided visual reference, including a newly drawn vector interpretation of the distinctive folded geometric **D**. The same master logo artwork, colors, and visual language are consistently used across the assets.

## Asset contents

| Folder | Included assets |
| --- | --- |
| `Brand/` | Gradient folded-D mark, single-color mark, white/dark wordmarks, transparent logo lockups, favicon, app icon, style guide, palette JSON |
| `LinkedIn/` | Two personal banners (1584 × 396), company banners (1512 × 256 and 1128 × 191), company avatar, blank profile backdrop, branded profile photo |
| `Web/` | Wide marketing masthead, website hero, separate background-only version, CAD illustration, presentation cover, email signature banner |
| `Social/` | Product launch post, LinkedIn portrait post, technical feature post, three separate carousel cards, social link preview, wide header, four-feature grid |
| `Icons/` | Four scalable illustrated feature icons (drawing review, revision compare, guideline checks, issue detection) |
| `Previews/` | Kit overview and light/dark logo comparisons |
| `Source/` | Source-generation Python scripts and asset manifest |

## File formats and quality

- **SVG**: editable resolution-independent artwork, including geometric mark, illustration lines, typography, and shapes. The SVG text uses Inter; if Inter is not available on the target computer, a similar fallback sans-serif is used.
- **PNG**: pixel-perfect exports at the dimensions indicated in the filenames or source manifest.
- **Backgrounds**: opaque on dark or white as intended; logo/mark SVGs and PNGs are transparent where needed.
- The profile photo uses the portrait already supplied in earlier Depth branding work. The blank profile backdrop is supplied separately.

## Important notes

The technical drawings are **illustrative artwork**, not validated manufacturing documents. The mark is an original editable **redraw inspired by the supplied image**, not an exact vector extraction from an original artwork file. Check visibility/cropping in the final platform because LinkedIn cover displays vary with device and browser.
